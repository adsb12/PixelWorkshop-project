# 픽셀작업소

윈도우 바탕화면에서 도트 일꾼이 걸어 다니고, 지정한 폴더에서 매일 날짜 폴더를 만들고 정리하는 C#·WPF 앱입니다.

## 실행

Windows 10/11에서 .NET 8 SDK로 실행합니다.

```powershell
dotnet run
```

런타임을 포함한 Windows x64 실행 파일을 만들려면 아래 명령을 실행합니다. 실행 파일을 사용할 위치에 먼저 옮긴 뒤 일꾼을 등록하세요. 작업 스케줄러에는 등록 당시의 실행 파일 경로가 저장됩니다.

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None
```

실행 파일은 `bin/Release/net8.0-windows/win-x64/publish/PixelWorkshop.exe`에 생성됩니다.

## 일꾼 등록

1. 화면 아래 왼쪽의 **작업소**를 누릅니다.
2. 이름과 대상 폴더, 생성 시간과 정리 시간을 입력합니다. 정리 시간은 생성 시간보다 늦어야 합니다.
3. **일꾼 만들기**를 누릅니다. 일꾼은 최대 5마리이며, 현재 작업 유형은 **날짜 폴더 만들고 정리하기**입니다.
4. 예약을 취소하려면 관리 창에서 해당 일꾼을 선택하고 **선택한 일꾼 해제**를 누릅니다. 이때 일꾼이 만들었던 폴더는 그대로 남습니다.

작업 스케줄러에는 일꾼마다 매일 실행 시간 두 개가 들어 있는 `PixelWorkshop-…` 작업이 하나 생깁니다. 현재 윈도우 계정으로 로그인한 상태에서 앱을 닫아도 예약은 실행됩니다. 절전이나 로그아웃 동안 놓친 예약은 다음 로그인에 몰아서 실행하지 않습니다.

생성 시간에는 PC의 현지 날짜를 `yyyy-MM-dd`로 표시한 폴더를 만듭니다. 정리 시간에는 그날 일꾼이 만든 폴더의 파일 시스템 식별자를 확인하고, 그 폴더가 여전히 비어 있을 때만 삭제합니다. 기존 폴더, 교체된 폴더, 내용물이 있는 폴더는 유지합니다. 설정과 마지막 작업 결과는 `%LOCALAPPDATA%\PixelWorkshop`에 JSON으로 저장됩니다.

일꾼은 주 모니터의 작업 영역 아래쪽을 걷고, 예약 작업이 끝나면 결과를 말풍선으로 보여줍니다. 일꾼과 말풍선을 클릭하면 뒤에 있는 앱이 클릭을 받습니다. 작업소에서 마우스 오른쪽 버튼을 누르면 앱을 종료할 수 있습니다. 파일 탐색기 추적과 사다리·로프 연출은 이후 버전의 범위입니다.

## Windows에서 동작 확인

빈 테스트용 상위 폴더에 일꾼을 등록하고, 몇 분 뒤에 생성·정리 시간이 오도록 설정합니다. 다음 세 가지를 확인합니다.

- 생성 시간에 만든 날짜 폴더를 비워 두면 정리 시간에 사라집니다.
- 일꾼이 만든 폴더에 파일이나 하위 폴더를 넣으면 정리 시간에도 남습니다.
- 날짜 폴더를 미리 만들어 두면 비어 있어도 남습니다.
